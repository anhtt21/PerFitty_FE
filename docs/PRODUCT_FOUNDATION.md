# PerFitty Product Foundation

## One-Liner

PerFitty helps young mobile users turn their wardrobe into a simple digital closet, create outfits quickly, plan what to wear, and ask friends for feedback.

## USP

- Digital closet focused on fast photo-first wardrobe management.
- Outfit planning with calendar and wear history as core MVP flows.
- Outfit Room for lightweight friend voting and chat before heavier AI features.

## Primary Personas

- Student: wants quick daily outfit ideas, low effort item upload, and friend votes.
- Office starter: wants weekday planning, simple style preferences, and calendar reminders.
- Streetwear user: wants outfit collections, favorite items, and social feedback before going out.

## MVP Scope

Must:

- Auth and profile foundation.
- Wardrobe item management.
- Manual and rule-based outfit creation.
- Outfit calendar.
- Outfit Room voting/chat foundation.

Won't for MVP:

- Virtual try-on.
- Full AI segmentation/detection.
- Custom trained fashion model.

## Core User Flows

1. Onboarding -> style preference -> wardrobe.
2. Camera/gallery -> item preview -> metadata -> save item.
3. Wardrobe -> select items -> create outfit -> save.
4. Outfit -> add to calendar -> mark worn/skipped.
5. Outfit -> create room -> invite friends -> vote/chat -> choose final outfit.
