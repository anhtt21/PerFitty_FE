# PerFitty Mobile

Expo React Native app using TypeScript, React Navigation, TanStack Query, and Zustand.

## Commands

```powershell
npm install
npm run start
npm run typecheck
npm run lint
```

## Structure

- `src/navigation`: typed auth stack and main bottom tabs.
- `src/screens`: PerFitty MVP screens.
- `src/components`: shared UI kit.
- `src/services`: API client and token storage.
- `src/store`: Zustand stores.
- `src/hooks`: app data hooks.
- `src/theme`: design tokens.
